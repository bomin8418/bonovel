# bo-novel

一款功能完善、用户友好的**终端小说阅读器**，使用 **Python 标准库**编写、零第三方依赖。

主要特性：.txt 小说导入与自动编码识别（UTF-8 / GBK / GB18030 / Big5 / UTF-16/32 带 BOM）、Kindle 式**分页**与**滚动**双模式阅读、章节目录跳转、书签管理、进度记忆与重启恢复、字号/行距/主题自定义、阅读速度（WPM）统计、快捷键操作与内置帮助、Windows / macOS / Linux 跨平台支持。

## 安装与运行

不需要安装任何第三方依赖，只要你的机器有 **Python 3.9 及以上**即可。

**推荐：一键 `./init.sh`（安装 + 验证 + 打印启动命令）**：

```bash
./init.sh                       # 安装（跳过）+ 验证 + 打印启动命令
RUN_START_COMMAND=1 ./init.sh  # 验证后直接启动
```

```bash
# 直接以模块方式运行（src 布局，需 PYTHONPATH=src）
PYTHONPATH=src python -m bonovel

# 查看版本 / 帮助
PYTHONPATH=src python -m bonovel --version
PYTHONPATH=src python -m bonovel --help

# 启动时直接导入一本小说
PYTHONPATH=src python -m bonovel /path/to/novel.txt

# 一次导入多本（拼接为一部）
PYTHONPATH=src python -m bonovel a.txt b.txt

# 自定义数据目录（书库/配置/日志存放处）
PYTHONPATH=src python -m bonovel -d /path/to/data
```

**免安装、全局以命令运行**（推荐给不想 `pip install` 的人）：

```bash
# Windows：在项目根目录
bonovel.bat                       # 打开书架
bonovel.bat 小说.txt -d D:\books   # 导入一本并指定数据目录

# macOS / Linux：脚本在 bin/ 下，可放入 PATH
./bin/bonovel --version
```

启动脚本会临时把 `src/` 加入 `PYTHONPATH` 再调用 `python -m bonovel`，
因此**无需 pip 安装**即可在任意目录以 `bonovel` 命令使用（直接调用脚本路径）。

> 也可以设置环境变量 `BONOVEL_DATA_DIR` 指定数据目录（优先于系统默认）。

## 快速开始

1. 运行 `./init.sh`（或 `PYTHONPATH=src python -m bonovel`）进入书架界面。
2. 按 `I`（或命令行为文件）导入一本 `.txt` 小说。应用会自动识别编码并解析章节。
3. 用 `↑`/`↓` 选中书名，按 `Enter` 开始阅读。
4. 阅读状态自动记忆，下次打开自动回到上次位置。

## 界面与操作

| 界面 | 入口 | 说明 |
|---|---|---|
| 书架 | 启动 / 阅读按 `q` | 已导入书目列表、进度百分比、导入/删除/选择 |

| 设置 | 阅读按 `c` | 自定义字口、行距、主题等 |
| 帮助 | 任意处按 `?` | 全量快捷键说明 |

## 阅读设置

- **字号**：`小 / 标准 / 大`（影响页面密度而非变宽字体）。
- **行距**：`紧凑 / 标准 / 宽松`。
- **主题**：`sepia`(暖黄护眼) / `classic`(白底黑字) / `dark`(夜间) / `paper`(纸张) / `terminal`(终端绿) / `plain`(命令行·单色，白底无彩色块，最贴合纯命令行观感)。
- **阅读模式**：`page`（整屏分页）与 `scroll`（逐行滚动），按 `p` 即时切换。
- **滚动步进**：滚动模式下每次按键滚动的行数（1~20）。
- **自动保存进度**：退出或换书时自动保存阅读位置（默认开）。

修改即时生效，`q` 返回时自动写入配置文件。

## 跨平台与终端要求

- **Windows 10/11**：Windows Terminal（推荐）、conhost 新版均可。应用启动时通过 `ctypes` 自动开启 VT 转义处理与 raw 模式（`msvcrt`）。
- **macOS / Linux**：任意支持 ANSI 的终端。输入层使用 `termios`/`tty`，退出时自动恢复终端属性。
- 使用 `pathlib` 处理路径，无平台差异。
- 若终端尺寸过小（如一行都不够显示正文），请放大终端窗口或调小字号。

## 常见问题

- **导入的中文乱码？** 应用通常能自动识别 UTF-8 / GBK / GB18030；极罕见情况下请确认文件确为纯文本且非二进制。
- **Windows 下按键或中文显示异常？** 确认使用 Windows Terminal 或新版 conhost，并运行在 UTF-8 代码页下（`chcp 65001`）。
- **终端口口无法容纳正文？** 放大终端或减小字号。
- **跨机器迁移书库？** 直接拷贝整个数据目录即可，小说原文件需保留原路径。
